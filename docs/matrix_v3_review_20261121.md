## 功能覆盖与不能混淆的边界

已实现并接入真实执行路径：全局事实向量 X、稀疏成员矩阵 B、来源分组权重、tag 关系三种统计与 witness、一次问题需求解析、原问/需求与事实/tag 匹配、固定预算候选与可选 tag 图、成熟 reranker 接口、原文装包/回答/引用校验、协议/批运行/回放/评分/分类成本。

以下不是被测试证明的能力，也不应在论文或实验解释中声称已实现：

1. **符号化的逻辑约束求解。** “都／分别”、时间、否定等依靠需求分解和回答提示；没有独立逐主体蕴含验证器，也没有对实体归一化后的答案集合执行可靠交集。相同事实集合用于两类问题本身并非 bug，但最后如何组合答案仍依赖 LLM。
2. **全量精确 tag 图。** tag 对候选由来源平衡质心 shortlist 筛选，再精算保留对；可能漏多模态桥接边。这是已声明的近似，不是完整图保证。
3. **独立端到端延迟基准与混合服务美元核算。** 当前有分阶段时间和 API 用量账；共享准备的批运行不是独立部署测速，也尚无多服务美元价目表。输出对应字段为 null/unknown，不会报告虚假节省。正式成本论文需补齐测量与价格配置。
4. **embedding/前端的语义正确性保证。** max 匹配的 tag 大小偏差、实体/关系混淆、前端改写错误、上游事实遗漏仍是研究风险。矩阵存储更多信息不等于这些问题已经解决。
5. **底层模型输出的可再生成性。** 回放固定模型输出并重算矩阵/路由/选择，不重新采样得到相同答案。

ANN、分层剪枝、训练式 attention、新委员会和额外 judge 属于之前明确排除的扩展，不作为当前主线缺件。
