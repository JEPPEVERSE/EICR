# 廉价 tag 选择器与原生 MRAgent：同标准配对诊断

日期：2026-11-22。**结论不确定，未达到进入确认轮的全部条件。**

完整执行 32 道题 × 2 臂 × 2 次重复，共 128 次请求。S 相对 N 的完整请求 API 费变化为 **降低 59.82%**；自动严格正确率为 N **45/64（70.31%）**、S **42/64（65.63%）**，差值 **-4.688 个百分点**。

人工复核未决项按同文同判、对两臂对称处理后，严格质量差 S−N 的可能范围为 **[-18.750, +18.750] 个百分点**。原始自动评分不是已完成人工裁定的成绩；资源投入门槛也不是统计非劣效检验。

## 公平比较的固定条件

- N 是冻结的本地 MRAgent 原生参考：两处 tag 评分均由原生模型执行。S 仅替换初始及扩展 tag 评分响应；原生图读取、工具、探索、回答和预算保持同一实现。
- 相同的 32 道预先选定问题、gold、会话图、事件/topic 向量、聊天模型、embedding 身份、价格、停止条件和上下文上限。每题两次均从问题解析到最终答案完整执行。
- 4 个会话 × 4 类题 × 每层 2 题；每题/试次配对，N/S 顺序随机交错且请求串行。每次重置已读状态；答案和在线教师评分不跨臂复用。本地查询缓存旁路，进程 PYTHONHASHSEED=0。
- 两臂由相同 deepseek-flash judge 按同一冻结 strict/lenient rubric 判分，只提供问题、参考答案和答案文本，隐藏臂名、成本和轨迹。相同文本同口径复用判断。strict 为主，lenient 为敏感性结果。
- 全部失败、重试和 fallback 保留分母与费用。质量先在每题两次运行内平均，再跨 32 题平均；本设计与 64 次请求直接平均等价。

自动审计核对了 128 个独立请求账本、完整配对、相同图视图、模型/向量身份、非 tag 请求参数及冻结标签。配对中首个执行的臂：{'native': 34, 'cheap_all': 30}。

## 解释范围与后续

本轮使用公开、此前检查过的会话和共享图。主样本在之前已预注册且未执行过，没有依据本轮主结果重新选题。N 指冻结的本地原生实现与本轮模型/向量配置，不是复现论文中的所有默认模型设置或官方汇总成绩。

聊天与 judge 为同一 deepseek-flash；计价依据 2026-11-22 官方周日非高峰费率：输入未命中 $0.15/M、命中 $0.003/M、输出 $0.60/M。模型名称与 endpoint 已冻结，服务商未暴露的后端变更不视为已验证固定。两臂引用 ID 的合法性在 analysis.json 独立报告：N 64/64 合法，S 63/64 合法；S 在 conv-43-qa067 的一次运行中把带来源文本的字符串作为引用，未满足来源 ID 合同，该答案原始 strict 判错。引用内容支持答案尚待盲审，不能与语义正确率混为一项。

判分差异、partial/时间边界和已知 gold 疑点已导出隐藏方法和费用的答案复核包：42 条运行记录，对应 27 个不同的待裁定文本键；来源支持另有 83 条去重盲审记录。没有用额外 LLM 判分冒充独立人工复核。本轮结束于诊断，未运行确认轮、cheap_initial 归因臂或第二 baseline。

自动判分差异集中在四道题：conv-26-qa057（徒步负面经历日期，S 一次只答月份）、conv-41-qa027（退伍军人聚会日期，S 两次答 20 May，参考为前一日 Friday）、conv-42-qa079（剧本数，N 两次答 three，S 两次答 at least 5）、conv-42-qa014（昵称，S 两次答 Jo，N 一次否认昵称）。这些是原始判分的差异说明，不是独立人工裁定。第一道题的 judge 还把“25 August 前一周”精确解释成 17 August，存在应复核的时间解释问题。

廉价臂的提前读取数量由 314 降至 226，标注来源召回由 82.29% 降至 71.28%；这与质量损失值得进一步核查，但不能据此断言因果。当前应先完成盲审，明确真实退化案例，再决定是否启动预声明的归因诊断；不在这 32 题上修改公式或阈值后重新宣称成功。

所有真实调用和冻结分析结束后，代码已将工具错误检测改为顶层结构化 error 结果或实际异常，避免正文子串误报。本轮执行源码另存于 execution-source，原协议和原始失败标记未被重签。修复后全仓 371 项测试通过，并在全部 128 条原始轨迹上与对称失败核查一致。修复后测试与当前代码身份另存 postrun-repair-manifest.json，不能冒充本轮执行版本。
