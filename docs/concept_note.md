# 基于下游证据的 Cue 表示：可行性与图结构建议

2026-11-18。设计建议；未实现本方案，未运行新的模型实验。

## 1. 本文固定的对象

Cue 是 MRAgent 式已有语义标签/关键词节点，不是当前问题临时生成的完整事实约束。问题前端负责映射到这些节点。表示算法输入是标签已经关联的证据与图结构，输出可缓存的标签向量。标签文字本身不需要送入文本 embedding 编码器；向量化在数学上仍属于一种图导出的 embedding。

本方案以用户澄清后的定义为准。此前 `entry_routing_design_v2` 中“问题约束组直接匹配原文”的主前端不作为本方案定义。这里保留已有 cue/事实单元，来源原文用于追溯与后续阅读，不将方法改为原文片段检索。

主建议：**加权证据向量是必需表示；保留直接通道的一步结构扩展是唯一首选增量；tag 保存为可选分面，不作为必经中间层。**

新方法可暂称“证据诱导的 Cue 表示”（Evidence-Induced Cue Representation，EICR）。这是工作名，不作名称独占或首创声明。图结构采用“带分面的 cue–evidence 二部图”。继承 MRAgent 的标签/事实抽取资产和检索接口应明确说明；方法差异来自表示计算及其作用，而非重命名。

重要适配细节：

2. 精确重复的事实单元先去重；同源但不同事实保留，来源族质量在它们之间分配。不能把同源所有事实机械合成一个证据事件。

4. 本地 cue 是直接抽出的词/短语，另会加入 speaker；并不自动具备可靠全局实体消歧、角色或谓词身份。新表示不能假设这些能力已存在。

## 3. 直接证据向量

设有 M 个 cue、N 个有来源的事实单元，关联矩阵为：

\[
R\in\mathbb R_{\ge0}^{M\times N},\qquad
R_{ce}=\text{cue }c\text{ 与 evidence }e\text{ 的直接关联强度}.
\]

第一版直接已有边取 1，无边取 0；相同 cue–evidence 重复路径取 max，不按路径数累加。模型或模糊匹配推得的边另列，不能冒充直接边。

令 W=diag(w_e) 为证据坐标权重，定义：

\[
x_c=R_{c,:}W^{1/2},\qquad
s_0(a,b)=\frac{x_ax_b^\top}{\|x_a\|_2\|x_b\|_2}.
\]

可行的最小权重起点：每个可确认 provenance family 等总质量，族内唯一事实单元均分。若有 G 个族，事实 e 所在族有 n_f 个单元，可用 w_e=1/(G n_f)。这控制已知派生副本，不保证识别所有未标复制，也不保证任意事实切分不变。以后对过宽 content 加坐标降权属于独立消融，不把多个未验证权重同时加进去。

开平方的意义：点积中同一坐标的贡献为 R_ae R_be w_e。若一个完全等价坐标拆成 k 个副本，每个分 w_e/k，且不新增截断，则直接点积和范数保持不变。任意语义拆分与重新构建结构通道不享有这个保证。

上述不变量要求显式守恒分配原坐标质量。若拆分后重新按新的 n_f 进行全族均分，该族其他坐标的质量也会变化，不自动满足不变量；默认来源族均分不是任意切分不变的保证。相反，仅新增完全无关的来源族、既有坐标与族内成员不变时，1/G 的共同缩放会在直接 cosine 中抵消；结构邻域或 tag 统计随新增资料变化时，结构通道不保证同样不变。

x_c 本身已经满足“根据下游证据得到标签向量”。一个标签连接多种场景，会在多个证据坐标上有质量，无需先把它们定义成一个事件。

不能通过给每个 cue 整行乘 IDF(cue) 来抑制泛化：cosine 会抵消这个正标量。泛化程度应单独记录/用于委员会参与权重，或者作用于不同证据坐标；不能声称整行缩放改变了余弦。

零向量表示当前无可用下游关联，不参与 cosine，输出 unavailable；不能用共同零向量或一个公共 unknown 节点制造关联。

## 4. 一步结构扩展：把间接关联与直接证据分开

直接 cosine 的局限是：两个标签连接不同但相关的事实单元，仍可能得到零。为此允许一个可选证据结构通道。

先构造有类型/来源说明的稀疏证据邻域 G_e。候选关系可以来自显式跨来源引用、已存具体 topic/上下文、经核对的结构链接；共同 tag 只能是弱候选线索。不能将同一 turn、同日、同 speaker 或同一宽泛 tag 直接视为同事件链接。

按固定规则抑制高频 hub、保留每个事实单元至多 k 个邻居，例如 k=8 的工程起点；对保留边行归一化得 P，无邻居行使用自身。方向、边型、来源和权重均记录。

用 lazy transition 保留自身：

\[
T=(1-\beta)I+\beta P,\qquad 0\le\beta<1,
\]

\[
y_c=x_cT.
\]

T 与 x 都非负。对于非零 x 且 beta<1，y 不为零。这里 y 是结构特征，未宣称为事实支持概率。一次扩展已经足够作为待验证增量；不先做无限 PPR 或 cue–cue 多跳闭包。

为避免结构通道因范数膨胀压过直接证据，**两个通道分别归一化，再拼接**：

\[
\hat x_c=x_c/\|x_c\|_2,\qquad
\hat y_c=y_c/\|y_c\|_2,
\]

\[
\boxed{v_c=[\sqrt{1-\lambda}\,\hat x_c,\ \sqrt\lambda\,\hat y_c]},
\qquad 0\le\lambda<1.
\]

最终 v_c 为单位向量，其 cosine 恰为：

\[
\boxed{s(a,b)=(1-\lambda)s_0(a,b)+\lambda s_1(a,b)},
\quad s_1(a,b)=\cos(x_aT,x_bT).
\]

因此 direct=0 时，最终相似度至多 lambda；不会因为一条结构桥就完全覆盖直接证据缺失。这个边界是数值贡献上界，不是语义正确性保证。

结构通道的未归一化点积为 x_a TT^T x_b^T，TT^T 自动半正定。分通道归一化后的整体 Gram 矩阵也是两个合法 cosine Gram 的非负加权和，仍半正定。但不要把最终分通道归一化版本误写成对所有 cue 共用一个未归一化 K 的简单 x_aKx_b^T；各通道分母不同。

beta 控制扩展距离内的自身保留；lambda 控制间接关联在最终相似度中的份额。第一轮应固定 beta，仅比较 lambda=0 与一个小的正值，例如0.2。数值仅是工程候选，不是已校准或已选优参数。

如果 P 来自 R^T R 共现，它是对同一信息的结构平滑，不是新增事实见证。必须记录这一来源，并与直接向量比较；不能因循环扩展产生更多路径就声称有更多独立证据。若没有可解释、可靠的邻域，令 lambda=0 即可，方法仍可执行。

## 5. tag 的去留：保留分面，取消必经层

推荐逻辑结构：

```text
已有 cue ──直接关联──> evidence fact ──origin──> 原始来源
                         │
                         └── 可选 facet/tag/topic/显式元数据
                                     │
                              可选的一步结构通道
```

tag 在本方案可以承担两个不同用途，不能混淆：

1. **忠实分桶**：保留 cue 在哪些 tag 下连接哪些事实。对多情境标签，可检查各分面向量，而不先把所有发生压成一个低维中心。
2. **结构候选特征**：有区分力的 tag 可帮助提出证据邻域，但不是同事件证据。若 tag 大多是 Cooking、Travel 等宽主题，不足以支持强扩展。

设每个事实有 tag t(e)，则可保存三元关联：

\[
A_{c,t,e}=R_{ce}\mathbf1[t(e)=t].
\]

没有 tag 时用未分类桶；有多个 tag 时记录明确分配权重、总和为1，避免多标签重复加质量。每个分面向量可由对应的 R 子行计算；同一个 cue 的多个分面仍是一份查询观察，不是多张委员会票。

**禁止错误重建：** 将 cue→tag 矩阵与全局 tag→content 矩阵直接相乘，作为新的“原有下游证据”。否则 cue A 与 content e 只要都连到 Cooking，就会被制造出一条原本不存在的 A→e 直接边。真正的直接关联必须来自现有三元记录/直接索引。

tag 没有提供额外区分性信息时，可以只保留用于导航，不进入向量扩展。没有必要为了维持三层外形而引入一个强制新层。只有增加了确切来源、类型和可验证结构语义时，才值得称为新的 context facet 设计，而不能仅把 tag 换名。

## 6. 为什么暂不选低秩或深度传播

| 方案 | 作用 | 主要风险 | 本轮取舍 |
|---|---|---|---|
| 加权关联向量 | 无训练、直接可追溯、多支持位置 | 不共享事实时低估关联 | 必需主表示 |
| 保留直接通道的一步扩展 | 连接部分分散但相关的证据 | 错误邻域会混合主题/事件 | 唯一优先增量 |
| SVD | 压缩、低秩平滑 | 罕见日期/对象差异被主主题吞没 | 规模需要时再单独比较 |
| NMF | 非负潜在成分、重叠主题 | 秩和优化选择；成分不是事件 | 后续可选 |
| 多步随机游走/PPR | 长程相关 | hub、循环与趋同，稀释事件边界 | 暂不作为主线 |
| 对 cue 文本做 embedding | 表面语义匹配 | 不利用个人记忆中的实际下游关系 | 对照或节点映射工具，不是主表示 |

第一版不强求低维。高维稀疏向量保留实际证据坐标，查询通常只涉及少量 cue，可以直接计算它们的交集和稀疏点积，不必离线算完整 M×M 相似矩阵。

## 7. 必须随相似度保存的诊断

保留：直接关联、扩展关联、来源族、cue 证据量/具体性、未映射状态、相似度的来源贡献，以及不同情境下的质量分布。

一个重要反例：二值等权时 E(A)⊂E(B)，有 cos(A,B)=sqrt(|E(A)|/|E(B)|)。具体活动 A 完全属于广泛人物 B 的记忆，cosine 仍可能很低。因此不能给所有 cue 使用同一个“低相似=错误”的规则。

可并列提供有方向的直接覆盖率作为诊断：

\[
\operatorname{cover}(A\to B)=
\frac{\sum_e w_e\min(R_{Ae},R_{Be})}{\sum_e w_eR_{Ae}}.
\]

二值情况下表示 A 的证据有多少同时被 B 覆盖。它不是因果、蕴含或事件概率；和对称 cosine 分字段保存。owner 等贯穿全库的 cue 可仅用于范围过滤，不贡献异常多数票。

另一个反例：A 同时连接做菜和购物，B 只连接做菜，C 只连接购物。等权简例中 cos(A,B)=cos(A,C)=1/sqrt(2)，但 cos(B,C)=0。A 是多情境连接点，不能借它宣称 B、C 同事件或进行相似度传递闭包。

因此保留完整证据坐标至关重要。pairwise 相似矩阵只是派生诊断，不能替代底层关联或高阶共同支持检查。在线若需要看某个候选范围中的局部关联，应保留全局向量与范围覆盖质量，不能只在对方法有利的小区域重归一化后当成全局证据。

## 8. 可识别性边界与沙拉例子

如果两个 cue 的下游关联完全相同，且所有可用结构也相同，任何只输入这些信息的确定性算法都会产生相同表示。若建图已丢掉 buy/use、主客体或时间归属，余弦、SVD、随机游走都不能凭空恢复。

沙拉例子中可以有已有标签“halloumi salad”“smoked paprika”“Mediterranean blend”“shopping”等；同一个商品标签同时关联采购与使用完全合理。表示保留两部分坐标即可，不需要预先宣布该商品属于某个唯一事件。

若现有图把完整原始 turn 作为同一坐标，且采购与使用都在其中，商品/动作标签可能得到相同下游。此时需要恢复重写事实单元与各自 origin 的差别，或提供更细的来源支撑边；不能仅升级向量算法。

tag 如果实际区分采购与烹饪，有助于分面观察。如果 tag 都叫 Food，它不能解决这一问题。不同日期、同一商品的重复购买也不会被粗 tag 唯一识别。

这条路线适合产生“哪些标签组合在这份记忆中支持不同区域”的查证信号。它不承诺把低 cosine 自动转换为某个标签错误，更不保证所有入口共同误指一个自洽经历时还能检测出来。

## 9. 可实施基础设施

最小表/文件：

```text
cue_nodes: cue_id, canonical_text, aliases, owner/snapshot
evidence_units: evidence_id, rewrite_text, origins, provenance_family
cue_evidence: cue_id, evidence_id, direct_weight, edge_origin
facets: evidence_id, tag/topic/type, provenance, allocation_weight
evidence_neighbors: from_id, to_id, type, weight, origin, direct_or_derived
cue_vectors: direct_sparse, expanded_sparse, norms, config/hash
```

数学构建流程：

1. 从已允许的冻结缓存读取关键词、重写句和 origin，校验 ID join、来源合法性和重复。
2. 构造稀疏 R 和证据坐标权重 W，计算 X=RW^(1/2)。
3. 可选构造有界稀疏 P，得到 Y=XT；记录所有新增邻域的依据。
4. 分通道规范化，缓存表示与行范数；查询只取命中的已有 cue 行。
5. 计算小规模 cosine 矩阵、覆盖率、来源贡献与缺失诊断。
6. 把诊断交给后续取证策略，继续保留原始问题和原文来源。

R 的存储随非零边数增长。若每个 evidence 至多 k 个邻居，结构乘法工作的粗略上界随 nnz(R)×k 增长；实际输出仍可能显著变密，应报告扩展率。不要构建所有 tag 下事实的完全两两图，其成本可能达 sum_t deg(t)^2。可以限制候选枚举和邻居数；截断后应记录向量 L2 误差或余弦偏差，不能宣称完全无损。

不增加默认离线 LLM 调用。现有 tag/关系不足时，结构通道关闭或作为低置信弱候选。额外抽取动作/角色属于另一个版本和成本账，不伪称矩阵算法本身获得了这些语义。

只变问题时标签向量可复用；新增记忆会改变权重、邻域与规范化，必须版本化并增量更新受影响部分或重建。不同用户/快照的 evidence 坐标不同，不能直接跨库比较 cosine。

## 10. 下一步设计判据

本轮不启动模型实验。后续首先应分别检验：

- 直接向量是否已提供有用的入口关联信号；
- tag/一步结构扩展是否在相同来源上改善分散证据，同时不混淆重复事件；
- 弱关联是否真的能帮助取证，还是主要反映标签宽窄和来源稀疏；
- 表示收益是否超过直接 cue 并集、加权共同邻居等简单对照；
- 压缩与扩展成本是否值得，以及正常问题是否受损。

这些对照尚未成立前，不能把工作名、余弦计算、图扩散或 Attention 类比当作创新已证明。最合理的候选贡献是：**来源可追溯、保留多情境的 cue 结构表示，及其对入口扰动下证据选择的独立帮助。**
